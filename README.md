# VytalTrack: Macro Tracker

VytalTrack is a mobile nutrition tracking app designed to make logging food fast and simple.

## Features

- Photo meal logging

- Barcode scanning

- Voice food logging

- Calorie and macro tracking

- Weight tracking

- Workout tracking

- AI-powered nutrition guidance

- Personalized nutrition goals

- Subscription features for advanced tools

## Tech Stack

- React Native

- Expo

- TypeScript

- Node.js

- PostgreSQL

- OpenAI

- RevenueCat

## What I Worked On

- Authentication

- Subscription and paywall logic

- AI-powered food analysis
